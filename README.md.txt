Это проект по созданию базы данных онлайн-магазина одежды. Тут предоставлены логическая,
концептуальная и физическая модели. Также есть скрипты по созданию нужных баз данных и их
заполнению, а также 10 различных запросов к этим БД. Также имеются несколько триггеров, индексов,
представления и функции.
