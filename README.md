# Онлайн-магазин одежды

Веб-приложение интернет-магазина одежды с бэкендом на Go и фронтендом, реализованным через JavaScript, HTML/CSS и React. Также содержит базы данных. 

## Основной функционал

- **Каталог товаров**: Просмотр списка товаров с фильтрацией по категориям, брендам, размеру и цене.
- **Поиск**: Поиск товаров по названию и описанию.
- **Карточка товара**: Страница товара с изображениями, описанием, выбором размера и отзывами.
- **Корзина**: Добавление/удаление товаров, изменение количества.
- **Оформление заказа**: Оформление заказа с указанием данных доставки.
- **Регистрация и авторизация** пользователей.
- **Отзывы**: Пользователи могут оставить отзывы на вещи.

## Технологии

**Backend:** Go, PostgreSQL, ORM

**Frontend:** JavaScript, CSS, HTML, React

**База данных:** PostgreSQL
